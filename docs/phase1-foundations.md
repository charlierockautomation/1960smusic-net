## Task detail

### 1. Static HTML listing pages
Problem: `blog/index.html` and every `blog/*/index.html` ship an empty
`#archive-grid` / `#posts-<type>` that `blog/shared.js` fills at runtime from
`data/posts.json`. Non-JS crawlers see no article links; 18 pages sit in GSC
"Discovered - currently not indexed".
- Add `gen/build_listings.py`: read `data/posts.json`, render the same
  `.genre-card` markup `postCardHtml()` produces, and write it into each
  listing page between `<!-- cards:start -->` and `<!-- cards:end -->`
  markers. Same sort order as shared.js (OTD by `seq`, others by date desc).
  Blog index keeps its per-type limit.
- Remove the runtime `renderArchive()` / `renderBlogIndex()` calls (or keep
  shared.js only as a no-op fallback). The HTML must be complete without JS.
- Add the script to CLAUDE.md Content Pipeline step 6: run it after
  `posts.json` is updated and before `generate_sitemap.py`.
- Acceptance: for every listing page, `grep -c 'class="genre-card"'` equals
  the posts.json count for that type; every slug appears in the raw HTML.
